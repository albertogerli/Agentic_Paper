## 2. Module-by-module responsibilities

| Module | Responsibility | Notes |
|---|---|---|
| `agentic_paper/__init__.py` | Public re-exports (`Config`, `ReviewOrchestrator`, `Review`, `register_provider`), `__version__`. | Keep tiny. |
| `cli.py` | `argparse`, `main()`. Translates CLI args → `Config` overrides, calls `asyncio.run(orchestrator.run(...))`. | Adds `--seed`, `--profile`, `--dry-run`. |
| `config.py` | Pydantic v2 models: `Config`, `AgentConfig`, `ProviderConfig`, `RoutingConfig`. YAML loader with whitelist validation. | Replaces `@dataclass Config`. |
| `routing.py` | Pure function `route(agent_name, complexity_score, config) -> (provider, model, thinking_budget)`. Per-agent override > tier mapping > global default. | Pure, easily testable. |
| `schemas.py` | Pydantic models for every structured output. JSON-schema export utility for providers to consume. | Single source of truth for output shape. |
| `paper.py` | PDF extraction (pdfplumber), text-file reading, `PaperInfo`, section detection regexes. | Migrated from `FileManager` + `PaperAnalyzer`. |
| `complexity.py` | `async def assess_complexity(text, provider) -> float`. Caches by content hash. | One job, well-isolated. |
| `orchestrator.py` | `ReviewOrchestrator`: builds agents, runs reviewers in parallel via `asyncio.gather`, runs coordinator, editor, summary serially after. Wires `AuditLogger`. | Drops sync Agent / threadpool path. |
| `audit.py` | `AuditLogger`: `run_id` (UUID4 short), `jsonl` writer, cost estimator (token rates per provider+model), prompt/response file dumper. | Per-call record: `{ts, agent, provider, model, prompt_hash, input_tokens, output_tokens, latency_ms, cost_usd, thinking_enabled}`. |
| `providers/base.py` | `LLMProvider` ABC: `async generate(messages, *, model, temperature, max_tokens, response_format, thinking_budget, seed) -> LLMResponse`. Plus `LLMResponse(text, usage, raw)`. | Async-first. |
| `providers/openai_provider.py` | Uses OpenAI SDK Responses API. `response_format` mapped to `{"type": "json_schema", ...}`. Reasoning effort for `o3`/`o4-mini` derived from `thinking_budget`. Removes the broken `cache_control` field. | OpenAI prompt caching is automatic; no client flag needed. |
| `providers/anthropic_provider.py` | Uses `anthropic` SDK Messages API. Structured output via a single forced tool whose `input_schema` matches the requested JSON schema. Extended thinking via `thinking={"type":"enabled","budget_tokens":N}` when budget set. | Documents seed-non-support. |
| `providers/google_provider.py` | Uses `google-genai`. `response_mime_type="application/json"` + `response_schema`. `thinking_budget` mapped to Gemini's thinking config. | Supports seed. |
| `providers/openai_compat_provider.py` | Subclasses `OpenAIProvider`, takes `base_url`. Strips features the local model can't do (json_schema → json_object fallback). | For vLLM / Ollama / DeepSeek / LM Studio. |
| `providers/stub_provider.py` | Returns canned `LLMResponse`s from a dict keyed by agent name. Used in tests only. | Never imported in prod. |
| `providers/smoke.py` | `python -m agentic_paper.providers.smoke [--config PATH]`. Pings every configured provider with a 1-token request; reports latency. | Used in CI and by users. |
| `agents/base.py` | `Agent` dataclass: `name`, `instructions`, `output_schema`, `provider_ref` (resolved via registry at runtime), `model`, `thinking_budget`, `max_tokens`. `async run(message, registry, audit) -> SchemaInstance`. | No more per-agent client construction. |
| `agents/<role>.py` | One file per agent. Contains: the system prompt (verbatim from current `main.py`), the output schema reference, the role's `AGENT_BASE_COMPLEXITY` value, and a builder function `build(config) -> Agent`. | Prompts live in their own files for easy editing. |
| `agents/coordinator.py`, `agents/editor.py` | Same shape but consume `List[Review]` and emit `CoordinatorAssessment` / `EditorDecision`. | Structured input, no more substring grep. |
| `reports/markdown.py` | Pure function: `render_markdown(result: ReviewResult) -> str`. Reads structured reviews, formats human-readable layout. | No more inline formatting in orchestrator. |
| `reports/json_export.py` | `export_json(result, path)`. Includes full audit log reference. | Provenance-friendly. |
| `reports/html_dashboard.py` | `render_html(result) -> str`. Severity color-coded (`minor` → blue, `major` → yellow, `fatal` → red). Vendors Tailwind by default; CDN is opt-in via config. | Drop emoji-only color heuristic. |

## 3. Public API surface

### A. CLI (after Prompt 9, `agentic-paper` console script; in the meantime `python main.py`)

```
agentic-paper PAPER_PATH
  [--config PATH]                    # default: ./config.yaml
  [--output-dir PATH]                # default: ./output/<run_id>/
  [--seed INT]                       # forwarded to providers that support it
  [--profile balanced|quality|fast|cheap]   # picks a preset routing
  [--provider-override AGENT=PROVIDER:MODEL]  # repeatable
  [--log-level DEBUG|INFO|WARNING|ERROR]
  [--dry-run]                        # prints routing + cost estimate; no API calls
```

### B. Python library

```python
import asyncio
from agentic_paper import Config, ReviewOrchestrator
from agentic_paper.schemas import ReviewResult

config = Config.from_yaml("config.yaml", seed=42)
orchestrator = ReviewOrchestrator(config)

result: ReviewResult = asyncio.run(orchestrator.run(paper_path="paper.pdf"))
print(result.editor.recommendation)            # "minor_rev"
for r in result.reviews:
    print(r.agent, r.recommendation, r.confidence)
```

### C. Provider plug-in (third-party adapters)

```python
from agentic_paper.providers import LLMProvider, LLMResponse, register_provider

class MyProvider(LLMProvider):
    async def generate(
        self, *, messages, model, temperature, max_tokens,
        response_format=None, thinking_budget=None, seed=None,
    ) -> LLMResponse: ...

register_provider("my_provider", MyProvider)
```

### D. Audit artefacts (added in Prompt 6)

```
output/<run_id>/
├── audit.jsonl                       # one record per provider call
├── prompts/<agent>.txt
├── responses/<agent>.json            # raw provider response
├── reviews/<agent>.json              # validated against schema
├── paper_info.json
├── report.md
├── report.html
└── result.json                       # ReviewResult
```

## 4. Migration steps (ordered, each ≤2h of real work)

> Each step ends with a green test suite and a commit. If a step grows, split it — don't push.

**Phase A — structural (Prompt 2)**

1. **Bootstrap tests + CI skeleton.** Create `tests/` with a trivial `test_smoke.py` that imports the package. Add `pytest`, `pytest-asyncio` to requirements. Add `.github/workflows/ci.yml` running pytest on 3.10/3.11/3.12. *Why first: every later step lands on a green baseline.*
2. **Lift non-orchestration classes** into modules without behaviour change. `Config` → `config.py`, `PaperInfo` + `FileManager` + `PaperAnalyzer` → `paper.py`, complexity scoring → `complexity.py`. Re-export from `main.py` so external imports still work.
3. **Split agents.** Move each `create_*_agent` prompt into `agents/<role>.py` *verbatim*. Move `AgentFactory` into `agents/__init__.py` as a builder.
4. **Split orchestrator + reports.** `ReviewOrchestrator` → `orchestrator.py`; markdown / executive summary → `reports/markdown.py`; HTML dashboard → `reports/html_dashboard.py`. `main.py` shrinks to `from agentic_paper.cli import main; sys.exit(main())`.
5. **End-of-Phase-A acceptance**: `python main.py data/fixtures/sample_paper.pdf --log-level INFO` produces the same outputs as the v1.0 main. Commit `refactor: split main.py into modules (no behaviour change)`.

**Phase B — multi-provider (Prompt 3)**

6. **Provider ABC + OpenAI adapter.** Define `providers/base.py`, port current OpenAI calls into `providers/openai_provider.py`. Refactor `Agent` to take a provider reference. Delete the broken `cache_control: ephemeral` field. Tests still green.
7. **Anthropic adapter.** Add `providers/anthropic_provider.py` with extended-thinking support. Add `ANTHROPIC_API_KEY` to README env section. Smoke test pings Claude.
8. **Google adapter.** Add `providers/google_provider.py` with thinking-budget support. Add `GOOGLE_API_KEY`.
9. **OpenAI-compat adapter + smoke entry point.** Add `providers/openai_compat_provider.py` (base-URL override). Implement `providers/smoke.py` — pings every configured provider with one token, reports `{provider, model, latency_ms, ok}`.
10. **Per-agent routing config.** Implement `routing.py`. Extend `config.py` schema to allow `agents.<name>.provider`, `agents.<name>.model`, `agents.<name>.thinking_budget`. Update `config_example.yaml` with a mixed-provider demo (e.g. methodology = Claude Opus 4.7 thinking, structure = Gemini Flash, results = `gpt-5.4-mini`).

**Phase C — structured outputs (Prompt 4)**

11. **Define schemas.** `schemas.py` with `ConcernItem`, `Review`, `CoordinatorAssessment`, `EditorDecision`, `ReviewResult`. Export JSON-schema for each.
12. **Wire structured-output across providers.** OpenAI `json_schema`, Anthropic forced tool, Google `response_schema`. Provider-agnostic call shape stays the same.
13. **Migrate reviewer agents.** Replace free-form prompts' "end with: REVIEW COMPLETED — X" tail with a "respond using the provided schema only" instruction. Validate with pydantic at agent boundary.
14. **Migrate coordinator + editor + summary.** Coordinator consumes `List[Review]`, emits `CoordinatorAssessment`. Editor consumes both, emits `EditorDecision` with enum recommendation. Remove all substring-grep ("accept as is" / "reject") fallbacks.
15. **Update reports.** Render structured data into the existing markdown layout (no user-visible change). HTML dashboard adds severity coloring.

**Phase D — tests (Prompt 5)**

16. **Real fixtures + stub provider.** Drop a tiny public-domain PDF into `data/fixtures/`. Implement `stub_provider.py` returning canned reviews keyed by agent.
17. **Write tests.** Targets per `Prompt 5`: parsing, complexity scoring determinism, schema validation, stub-driven agent runs, parallelism (3 agents finish in <1.5× slowest), report generation. Aim for 60% coverage. Don't gold-plate.

**Phase E — reproducibility (Prompt 6)**

18. **Run-scoped output dirs + audit log.** Generate `run_id` at orchestrator init. Move log file under `output/<run_id>/`. Implement `audit.py`. Save prompts and raw responses.
19. **`--seed` flag.** Plumb through to OpenAI / Google. Document Anthropic limitation in README.

**Phase F — meta (Prompts 7–9)**

20. **R component analysis.** Write `R_COMPONENT_DECISION.md`. Recommend A/B/C. Wait for user to pick.
21. **README rewrite.** Per Prompt 8: honest sections, real placeholders, accurate badges, cost/latency numbers from real runs, comparison paragraph.
22. **Packaging.** `pyproject.toml` (hatchling), console entry point, `requirements-lock.txt`, release workflow.

**Phase G — optional (Prompt 10)**

23. **FastAPI + HTMX web UI.** Only if Physalia demo demands it. Hard stop at 3h budget.

Total estimated work: **22 steps × ≤2h ≈ 30–40h** of actual coding, spread across the prompt sequence.

## 5. Cross-cutting design decisions

- **Async-first.** The provider interface is async. Drop the synchronous `Agent` and the `loop.run_in_executor` thread-pool fallback — they exist today only because the AsyncAgent path was never actually wired up.
- **Pydantic v2** for both config and output schemas. One library, one validation story.
- **No orchestration framework.** No LangChain / LangGraph / CrewAI / AutoGen. The 9-agent parallel + 3-agent serial flow is `asyncio.gather` + three awaits. A framework would add transitive deps and fight us on thinking budgets and structured outputs.
- **Tenacity** stays for retries; no custom loop.
- **No vendor lock-in via SDK quirks.** Each provider's quirks (Responses API for OpenAI, forced-tool for Anthropic, `response_schema` for Google) are confined to its adapter file.
- **Determinism contract.** When `--seed` is set, we propagate to every provider that supports it. We document that Anthropic ignores seeds and recommend pairing with `temperature=0`. The audit log records whether seed was honored.
- **Cost estimation** uses per-(provider, model) token-rate tables in `audit.py`. Out of date by definition; explicit "rates as of YYYY-MM" comment plus a config override.

## 6. "Do NOT do" list

Things that are tempting but distracting in this refactor:

1. **Do not rewrite the agent prompts during the structural refactor.** Move them verbatim. Refine in a later, dedicated prompt-engineering pass.
2. **Do not introduce LangChain / LangGraph / CrewAI / AutoGen / LlamaIndex.** The orchestration is ~50 lines of asyncio; a framework adds transitive dependency hell and obscures direct provider control (thinking budgets, structured outputs).
3. **Do not build a RAG / vector store layer for the literature agent.** Cross-PubMed / arXiv checking is a separate project. The current behaviour is "judge based on the paper text"; keep it that way.
4. **Do not over-engineer the provider abstraction.** No `BasePrompt`, no `PromptTemplate`, no `MessageBuilder`, no plug-in lifecycle hooks. The interface is one async method.
5. **Do not implement function calling / tool use beyond what's needed to force structured JSON.** The agents are not tools-of-tools; each emits one structured review.
6. **Do not add a database.** Audit lives on disk under `output/<run_id>/`. SQLite is overkill until usage justifies it.
7. **Do not replace the heuristic section identifier with an LLM call** in this refactor. It mostly works; rework it later if it becomes a hotspot.
8. **Do not delete `agentic_paper_R/` before Prompt 7's decision.** The user picks A/B/C.
9. **Do not retire `main.py`.** Keep it as a thin shim so users' shell scripts keep working.
10. **Do not preempt the roadmap.** Batch processing, arXiv/PubMed integration, citation networks, Zotero export — all explicitly out of scope.
11. **Do not pin SDK versions to a minor** in `pyproject.toml`. Caret pin in `pyproject.toml`; exact in `requirements-lock.txt`.
12. **Do not catch and swallow `KeyboardInterrupt`** as exit code 1. Standard is 130 (128 + SIGINT).
13. **Do not log API keys**, even at DEBUG. Add a redacting log filter as a small one-off.
14. **Do not add Streamlit / Gradio** for the (optional) web UI. Prompt 10 specifies FastAPI + HTMX — stay there.
15. **Do not couple the orchestrator to the report layer.** Orchestrator returns `ReviewResult`; reports consume it. Headless callers (the future plugin in the bonus prompt) should get the structured object without ever touching markdown or HTML.

## 7. Acceptance criteria for v2.0

Considered "shippable" when:

- `agentic-paper data/fixtures/sample_paper.pdf` produces identical *or strictly better* output than current `python main.py`, against the same paper.
- `python -m agentic_paper.providers.smoke` reports `ok: true` for every configured provider.
- `pytest -q` passes on Python 3.10 / 3.11 / 3.12 in CI.
- A mixed-provider config (Anthropic + OpenAI + Google in the same run) completes end-to-end.
- `output/<run_id>/audit.jsonl` is complete enough to reconstruct the run.
- README has no `yourusername`, no `your.email`, no false `pytest tests/` claim, no fictional model in a badge.
- A second person can `pip install -e .` and review a paper without reading the source.
